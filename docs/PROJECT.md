# ایده‌ی پروژه

**WhistleSong**: یک وب‌پیج که هر آهنگی را می‌گیرد، ساختارش را می‌فهمد (ملودی، ریتم، فراز و فرودها، پویایی صدا)، و همان آهنگ را **با صدای سوت زدن** بازسازی می‌کند — مثل «کاور»، انگار کسی با دهان آن را سوت می‌زند.

## اصول محصول
- ورودی: هر فایل صوتی (mp3, wav, m4a, ...).
- خروجی: فایل صوتی قابل پخش و دانلود، وفادار به آهنگ اصلی (نت‌ها، ریتم، تمپو، بالا/پایین و بلند/آرام).
- شنیده‌شدن «انسانی»: لغزش بین نت‌ها (glide)، ویبراتو، نفس/هوا در صدا، شروع و پایان طبیعی نت، نه صدای خشک سینتی‌سایزر.
- فقط سمت مرورگر (بدون سرور) تا حد ممکن: ساده، رایگان، خصوصی (فایل کاربر جایی آپلود نمی‌شود).
- روی GitHub Pages منتشر شود؛ بیلد با GitHub Actions.

## خارج از محدوده (فعلاً)
- شبیه‌سازی صدای یک سوت‌زن مشخص؛ سوت چندنفره‌ی هارمونی (شاید بعداً).
