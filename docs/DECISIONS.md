# تصمیم‌ها و سؤال‌های باز

## تصمیم‌های گرفته‌شده
- ۲۰۲۶-۱۱-۱۹: ابتدا بحث؛ **کد فقط با دستور صریح کاربر**.
- ۲۰۲۶-۱۱-۱۹: خروجی = وب‌پیج روی GitHub Pages، بیلد با Actions.
- ۲۰۲۶-۱۱-۱۹: اسناد راهنما به صورت فایل `.md` در ریپو نگهداری می‌شود.

## سؤال‌های باز
1. همه‌چیز در مرورگر (خصوصی/رایگان، کیفیت محدودتر) یا با بک‌اند (کیفیت بهتر، هزینه/سرور)؟
2. فقط ملودی اصلی (یک سوت) یا چند سوت برای هارمونی/بیس؟
3. ورودی: فقط فایل آپلودی یا لینک (یوتیوب و...) هم؟ (لینک مشکل حقوقی/فنی دارد)
4. زبان رابط: فارسی، انگلیسی، یا هر دو؟
5. شخصیت صدای سوت: طبیعی/نرم، یا تیز و کارتونی؟
6. طول بیشینه‌ی آهنگ؟
