# تصمیم‌ها و سؤال‌های باز

## تصمیم‌های گرفته‌شده
- ۲۰۲۶-۱۱-۱۹: ابتدا بحث؛ **کد فقط با دستور صریح کاربر**.
- ۲۰۲۶-۱۱-۱۹: خروجی = وب‌پیج روی GitHub Pages، بیلد با Actions.
- ۲۰۲۶-۱۱-۱۹: اسناد راهنما به صورت فایل `.md` در ریپو نگهداری می‌شود.

- ۲۰۲۶-۱۱-۱۹: همه‌چیز در مرورگر (بدون بک‌اند) فعلاً.
- ۲۰۲۶-۱۱-۱۹: فقط یک سوت (ملودی اصلی) در نسخه‌ی اول.
- ۲۰۲۶-۱۱-۱۹: زبان رابط: انگلیسی.
- ۲۰۲۶-۱۱-۱۹: حس صدا: طبیعی و نرم.
- ۲۰۲۶-۱۱-۱۹: صدای سوت با سنتز ساخته می‌شود (نه نمونه‌ی ضبط‌شده)؛ ضبط واقعی فقط اختیاری برای مرجع تنظیم.
